# 生图提示词

## 全局统一风格

适合公众号 AI 技术深潜文章的半扁平矢量插画。整体视觉克制、清晰、偏工程手册感；背景为干净的浅灰白或极淡冷色，主体使用深蓝灰、青绿色、少量橙色作为强调色，避免大面积渐变和装饰性光斑。图形以结构图、流程图、系统示意图为主，线条统一、边角轻微圆角，人物如出现则保持小比例、无表情夸张。优先生成无文字版本，关键中文标签后期叠加；如必须出现文字，只保留极少英文关键词，使用简洁无衬线字体，不要乱码。

## fig1-lwm-loop.png

- **用途**：开篇 / 解释语言世界模型机制。
- **核心表达**：Agent 输出动作，语言世界模型预测环境下一步观测，二者形成训练闭环。
- **生图提示词**：

```text
适合公众号 AI 技术深潜文章的半扁平矢量结构图。主题是“语言世界模型扮演环境”：左侧是 Agent 模块，输出一个动作箭头；右侧是 Language World Model 模块，接收历史观测和当前动作，输出下一步环境观测；下方形成一个闭环训练流程。画面应突出“预测环境反馈”而不是“预测下一动作”。整体采用浅灰白背景、深蓝灰主线、青绿色高亮、少量橙色强调，线条干净统一。尽量无文字，预留后期叠加标签的位置。
```

- **生图提示词**：

```text
适合公众号 AI 技术深潜文章的半扁平矢量信息图。画面中央是“Agentic Environments”抽象中心节点，向外分成两组：文本域包含工具调用、搜索、终端、软件工程四类图标；GUI 域包含手机、浏览器、桌面系统三类图标。不要绘制复杂文字，使用图标和分组形态表达分类关系。浅灰白背景，深蓝灰结构线，青绿色表示文本域，橙色表示 GUI 域，风格克制、清晰、工程化。
```

## fig3-training-pipeline.png

- **用途**：第四节 / 展示三阶段训练配方。
- **核心表达**：CPT 注入环境知识，SFT 激活推理，RL 锐化保真度。
- **生图提示词**：

```text
适合公众号 AI 技术深潜文章的半扁平矢量流程图。主题是三阶段训练流水线：第一段是大量动作-观测轨迹进入模型，表示 CPT 注入环境知识；第二段是精选推理样本进入模型，表示 SFT 激活下一状态预测推理；第三段是评分器与规则校验环绕模型，表示 RL 提升模拟保真度。流程从左到右，结构清楚，避免过多文字。浅灰白背景，深蓝灰主体，青绿色表示训练数据，橙色表示奖励与校验。
```

- **核心表达**：AgentWorldBench 用五维 rubric 评估世界模型输出，其中 Factuality 是需要谨慎看待的维度。
- **生图提示词**：

```text
适合公众号 AI 技术深潜文章的半扁平矢量数据卡片。画面展示一个评测仪表板：中央是一张简洁的评分卡，围绕 Format、Factuality、Consistency、Realism、Quality 五个维度的抽象刻度；Factuality 维度用橙色提示，其他维度用青绿色或蓝灰色。不要生成具体数字和中文文字，预留后期叠加标签。整体像技术报告中的评测卡片，简洁、专业、可读。
```

## fig5-two-uses.png

- **用途**：第六节 / 展示两种应用路径。
- **核心表达**：同一个语言世界模型既可以作为环境模拟器，也可以作为 Agent 的预训练基座。
- **生图提示词**：

```text
适合公众号 AI 技术深潜文章的半扁平矢量架构图。画面中央是 Language World Model，向左连接“环境模拟器”路径：Agent 在模拟环境中试错并获得反馈；向右连接“预训练基座”路径：世界建模能力注入 Agent，使其在行动前预测后果。两条路径并列、对称但不复杂。浅灰白背景，深蓝灰主体，青绿色表示模拟反馈，橙色表示能力迁移。尽量无文字，预留后期叠加标签。
```
