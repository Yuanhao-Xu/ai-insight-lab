# Qwen-AgentWorld:语言世界模型作为通用智能体的认知基座

> 论文：[arXiv:2606.24597](https://arxiv.org/abs/2606.24597) · 博客：[qwen.ai](https://qwen.ai/blog?id=qwen-agentworld) · 代码与模型：[GitHub](https://github.com/QwenLM/Qwen-AgentWorld) · [HuggingFace](https://huggingface.co/collections/Qwen/qwen-agentworld) · [ModelScope](https://modelscope.cn/collections/Qwen/Qwen-AgentWorld) · [AgentWorldBench](https://huggingface.co/datasets/Qwen/AgentWorldBench)

---

## 摘要

Qwen-AgentWorld 提出**语言世界模型(Language World Model, LWM)**:用语言模型对环境的状态转移动态建模——在给定历史观测与智能体动作的条件下,经长链思维推理预测下一观测。论文发布两个模型(35B-A3B 与 397B-A17B),给出"继续预训练→监督微调→强化学习"三阶段训练配方,构建评测基准 AgentWorldBench,并论证世界建模的两种用途:作为可控的环境模拟器支撑智能体强化学习,以及作为智能体的预训练基座。397B 模型在 AgentWorldBench 取得 58.71 分,超过 GPT-5.4(58.25)。

---

## 1　研究动机

智能体训练长期受制于真实环境:延迟高、成本大、难以并行,且存在不可逆副作用(误删文件、误发请求)。若能用一个可大规模并行、**可控**且高保真的学习型环境替代或增广真实环境,智能体的强化学习便可摆脱这些约束。

本文的核心思路是让语言模型"扮演环境本身":不再预测智能体该做什么,而是预测环境在某动作下会返回什么。这一思路有清晰的学术谱系——世界模型概念可追溯至模型化强化学习(Sutton, Dyna, 1991)与基于循环网络的环境建模(Schmidhuber),并由 Ha & Schmidhuber《World Models》(2018)普及;LeCun(2022)的 JEPA 主张在表示空间而非像素空间预测;Hao et al. 的 RAP(EMNLP 2023)首倡"同一语言模型兼任世界模型与推理体"。Qwen-AgentWorld 的贡献不在于首倡该理念,而在于将其工程化、规模化为可训练、可评测的智能体基础设施。

## 2　形式化与七大交互领域

世界模型学习状态转移 `p(o_{t+1} | o_≤t, a_t)`:给定历史观测与当前动作,预测下一观测。论文以统一的(动作, 观测)轨迹模式表示七类异构领域,并按观测形态分为文本域与 GUI 域。

| 领域 | 场景 | 动作 | 观测 | 主导能力 | 类别 |
|---|---|---|---|---|---|
| MCP | 标准化工具调用 | JSON 工具调用 | 工具响应(文件/数据库/API) | 事实性世界知识 | 文本 |
| Search | 联网检索 | 检索 / 网页抽取 | 对话历史 + 检索结果 | 事实与检索 | 文本 |
| Terminal | 命令行 | Bash 命令 / 按键 | 终端输出(stdout + 提示符) | 长上下文因果推理 | 文本 |
| SWE | 软件工程 | 读取 / 编辑 / 执行 | 工具输出 + 代码 diff | 代码执行推理 | 文本 |
| Android | 移动端操作 | 触控 / 滑动 / 输入 | UI 视图层级 + 应用状态 | 界面状态推理 | GUI |
| Web | 浏览器操作 | 点击 / 输入 / 导航 | 无障碍树 + 浏览器状态 | 界面状态推理 | GUI |
| OS | 桌面系统操作 | 鼠标 / 键盘 | 无障碍树 + 窗口/应用状态 | 界面状态推理 | GUI |

**关键设计**:GUI 三域不预测屏幕像素,而预测**无障碍树(accessibility tree)/ 视图层级**。这类结构化表示更紧凑,且与智能体真正读取并据以决策的接口一致,与 LeCun"避免像素级生成"的主张一脉相承。其中 DOM(Document Object Model,文档对象模型)指浏览器对 HTML 解析所得的元素树;在 Web 域,一次交互引起 DOM 变化,世界模型预测的即是更新后的页面结构。

## 3　三阶段训练配方

三阶段的逻辑是"注入知识 → 激活推理 → 锐化保真"。论文以逾 1000 万条真实环境交互轨迹为数据基础。下文以一个论文实例(Figure 3)贯穿说明:在 Terminal 域执行 `pip install torch`,环境为 CUDA 11.8、仅余 2 GB 磁盘。

### 3.1　继续预训练(CPT):注入环境知识

以下一词元预测在交互轨迹与专业领域语料(法律、医疗、金融)上训练,让模型"见过世界的样态"。此阶段使用**非思维轨迹**——纯粹的(动作, 观测)对,不含任何显式推理链;先记住世界长什么样,解释能力留待下一阶段。

本阶段的关键贡献是**轮次级信息论损失掩码**:许多观测只是回显动作或输出样板内容,对其计损会让模型学会复读。论文用四个表层统计量量化每个(动作, 观测)对的信息量:

- Overlap `OL = |W_act ∩ W_obs| / |W_act|`——观测对动作词汇的回显程度
- Novelty `Nov = |W_obs \ W_act| / |W_obs|`——观测中真正新增信息的比例
- Jaccard `Jac = |W_act ∩ W_obs| / |W_act ∪ W_obs|`——双向词集相似度
- Length ratio `R = |obs| / |act|`——字符级长度比

据此将对话轮划归七类并差异化掩码:检索类(Nov ≥ 60%, R > 1)全额计损,回显类(OL ≥ 70%, Nov < 30%)仅保留 5%。被掩码的轮不计入损失,但仍保留为上下文。这是一种低成本而有效的信息量过滤,使算力集中于真正承载状态转移的轮。

### 3.2　监督微调(SFT):激活显式推理

此阶段将"下一状态预测"激活为显式思维模式:模型在给出观测前先推理。例如先判断"CUDA 11.8、磁盘 2 GB、依赖体积超限 → 应在解包阶段失败",再输出磁盘不足的报错。

训练数据经**拒绝采样**构造:自 10,250 条候选查询出发,每条由通用推理模型生成 3 条候选轨迹,经独立评委评分,取最优且过阈者保留,最终留下 7,094 条(保留率 69.2%),各域保留率介于 59.5%–86.5%。此外按样本随机采样 10 种系统提示变体(v2–v11)以增强泛化。

### 3.3　强化学习(RL):锐化模拟保真度

采用 GSPO,结合 **rubric 与规则混合奖励**:五维 rubric(Format、Factuality、Consistency、Realism、Quality,由 LLM 评委评定)与规则验证器按 **9:1** 加权。论文针对三类失效模式分别设计对策:多轮展开引致的奖励崩溃(改为单轨迹单轮评估)、开放式 rubric 的奖励塑形、以及自夸式刷分(以内容类型分类抑制)。此阶段使报错文本的格式、错误码与措辞被打磨至与真实终端难以区分。

三阶段对比可概括为:CPT 用非思维裸轨迹注入知识,SFT 用带推理链的精选样本激活显式思维,RL 用混合奖励提升保真度。

## 4　推理模式的涌现

高保真的下一状态预测需要推理、知识、指令遵循与长上下文处理的协同。论文观察到训练后涌现出三种可解释的思维行为:

- **多步因果推理**:在 Terminal、SWE 域沿命令序列与代码执行追踪状态变更。
- **深思式自我纠正**:生成过程中识别并修正自身不一致后再定稿。
- **信息泄露防护**:主动约束预测,避免提前暴露"未来信息"。

强化学习进一步锐化微观保真度,涌现出领域特化的约束验证,如字符级字节运算与 API schema 合规。维度分析显示,Factuality 在 RL 阶段相对增益最大(11.3%),却始终是最弱维度——表明事实性世界知识是环境模拟中最难的部分。

## 5　评测基准与主结果

**AgentWorldBench** 取 5 个前沿模型在 9 个成熟基准(Terminal-Bench 1.0/2.0、SWE-Bench Verified、OSWorld-Verified 等)上的真实交互轨迹,构造含真值观测的 2,170 条评测样本。评测采用五维评分(1–5,归一至 0–100)与参考对照式评判;跨评委 Spearman 等级相关 ρ=0.92–0.99,证明评分稳健。

主要结果:

| 模型 | AgentWorldBench 总分 | 对照 |
|---|---|---|
| Qwen-AgentWorld-397B-A17B | **58.71** | > GPT-5.4(58.25) |
| Qwen-AgentWorld-35B-A3B | **56.39** | > Claude Sonnet 4.6(56.04) |

隔离训练增益:397B 自基线 54.74 提升至 58.71(+3.97);35B 自 47.73 提升至 56.39(+8.66)。分域看,397B 文本域平均 +3.35,GUI 域平均 +4.92。

## 6　世界建模在智能体训练中的作用

世界建模能力有两种兑现路径。

### 6.1　作为解耦的环境模拟器

论文表明 Qwen-AgentWorld 可模拟 4,000 个真实 OpenClaw 环境用于智能体强化学习。其核心能力是**可控模拟**:通过注入一条模拟指令,将世界模型调制为指定的环境状态。论文给出的实例包括:

- **Search 域**:为每条轨迹标注逆向构造的模拟指令,含目标查询、参考答案与不泄露约束,使模拟结果含线索而不直接给出答案。
- **Terminal 域**(Figure 3):模拟指令指定"CUDA 11.8 驱动、仅余 2 GB 磁盘",据此预测 `pip install` 在解包阶段因磁盘不足而失败。

此外,论文还设有面向 MCP 的环境自适应模式。

论文报告,以模拟环境做强化学习的增益**超过仅依赖真实环境的训练**。这一结论需正确理解:就保真度而言,模拟器的上限即真实环境,不可能"更真";真正被比较的,是"以模拟环境训练所得策略"与"以真实环境训练所得策略"在同一真实测试集上的表现。模拟环境之所以能在训练效用上胜出,在于它可控(可构造更难、更具针对性的训练实例)、信号快而稳且高度并行,并能覆盖真实数据中罕见的长尾情况。

### 6.2　作为智能体的预训练基座

世界建模训练可作为预热,使智能体学会"预测未来状态以优化动作选择"。论文在 Terminal-Bench 2.0、SWE-Bench Verified/Pro、BFCL v4、Claw-Eval、QwenClawBench、WideSearch 等基准上均观察到一致增益。

两条路径同源:前者提升训练效率,后者提升智能体能力。

---

## 7　局限与未来方向

事实性始终是最弱维度,事实性世界知识的建模仍具挑战。GUI 域以纯文本(无障碍树/视图层级)表征观测,对视觉理解的覆盖有限。未来方向包括拓展至七领域之外、增强跨域泛化、进一步提升世界建模的事实性,以及与其他智能体架构集成。

---

## 8　结语

Qwen-AgentWorld 将"语言模型即世界模型"从一种推理技巧,推进为可训练、可评测、可规模化的智能体基础设施。其两项最具信号的结论是:可控模拟训练在效用上可超过仅用真实环境的训练;世界建模可作为通用智能体的有效预训练。这为缓解智能体训练对真实环境的依赖提供了一条切实可行的路径。
