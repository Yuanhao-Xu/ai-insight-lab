## 一句话主题
在「工程栈」叙事下，一台只会预测下一个 token 的大模型（「打字机」），如何被一道工序一道工序地装成一个能查资料、调工具、自己推进任务的**智能体**。

## 全链路 6 环
① 模型打字机 → ② 推理引擎 → ③ 接口与上下文 → ④ 工具调用 → ⑤ 知识与记忆 → ⑥ 装进循环（智能体诞生），外加 ⑦ 护栏与代价。
（你最初给出 ①②⑥ 三环，③④⑤ 为调研补全。）

- 6 路并行深度调研（每环一名研究员）+ 推理引擎环的子搜索群 + 2 路比喻调研；覆盖论文 / 官方文档 / 高 star GitHub / X 高赞 / 知乎·B站·公众号。
- **严谨口径**：硬事实锚定论文、官方文档、代码库；X / 知乎的点赞收藏量级**仅作「读者关心什么」的热度参考，不当事实依据**。
- **数字会变**：所有 GitHub star、下载量、吞吐基准均为调研时点（2026 年 6 月）数据，引用前请复核。
- 每环均附「常见误解 / 经不起推敲的坑」，正文写作前对照自查。
